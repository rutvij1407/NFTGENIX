**NFTGENIX: NFT Marketplace Landing Site**

Live site: https://nftgenix.vercel.app

A responsive front end design for an NFT marketplace, built as a web design exercise.

**Pages**

* Home with featured collections
* Explore
* About us
* Login

**Scope**

This is a static design with HTML, CSS and JavaScript. It has no backend, wallet connection or real marketplace data, and nothing on it can be bought or sold.

**Run it**

Open index.html in a browser.
